# Stacks, Queues, and Deques

This projects implements six data structures in C++: 

- Array Stack
- Linked List Stack
- Array Queue
- Linked List Queue
- Array Deque
- Linked LIst Deque

Each data structure supports insertion, removal, and displaying elements. The program tests at least 10 operations per structure and checks how each handles empty conditions. 

## How to Compile 

Compile the program using a C++ compiler: 

g++ -std=c++17 stack_queue_deque.cpp -o stack_queue_deque

## How to Run

Run the compiled program: 

On Windows:

stack_queue_deque.exe

On Mac/Linux:

./stack_queue_deque
